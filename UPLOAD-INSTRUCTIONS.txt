JG ELECTRIC V6 UPLOAD INSTRUCTIONS

1. Download and unzip this package.
2. In your GitHub repository, upload ALL files and the assets folder to the repository root.
3. Choose Replace when GitHub reports files with the same names.
4. Confirm that index.html, style.css, main.js, logo.svg, favicon.svg, and the assets folder are at the root.
5. Wait 2-5 minutes for GitHub Pages to rebuild.
6. Open https://jgelectricnh.com and refresh the browser.

Important: Do not upload the outer ZIP as a folder. Upload the contents of the ZIP.
